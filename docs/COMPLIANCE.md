# Compliance — legal requirements for phase A

> **Scope rule (BRIEF §4):** this file lists what French/EU law requires for phase A (third-party amicable collection), and nothing more. No certifications, no voluntary frameworks. Anything uncertain goes to [Open questions](#9-open-questions), not into code.
>
> **Sources:** article texts were read on 2026-11-07 from Légifrance via LibreJustice (links below go to LibreJustice, which mirrors Légifrance and links to the official source). Article versions are the ones in force on 2026-11-07 unless stated.
>
> **Status of every row:** *to validate by counsel* (✅ = text verified verbatim; ⚖️ = interpretation needs counsel; ❓ = unverified source).
>
> **Enforcement points** are *planned* names, consistent with `docs/ARCHITECTURE.md` (Supabase Postgres + RLS + `SECURITY DEFINER` functions; Python worker for the calculation engine, flow executor and channel adapters). They will be renamed if the architecture changes; the test column is the contract.

## Legend for enforcement layers

| Layer | Meaning |
|---|---|
| **DB** | Postgres constraint, trigger or `SECURITY DEFINER` function. Cannot be bypassed by any client. |
| **Engine** | Calculation engine in the worker (`worker/src/collectoo_worker/engine/`). Driven by rule packs. |
| **Guardrail** | Pre-send check in the worker (`worker/src/collectoo_worker/guardrails/.py`), run before every outbound action. Flows cannot skip it. |
| **Template** | Locked legal blocks in the template system (`template_block.locked = true`) plus a render-time validator. |
| **Ops** | Business/organisational obligation. Not code. Tracked here so it isn't forgotten. |

## 1. Third-party amicable collection (CPCE)

Scope: R124-1 applies to anyone collecting debts amicably for third parties, habitually or occasionally ([R124-1](https://librejustice.fr/norm/fr/code-des-procedures-civiles-d-execution/r124-1)). Missing an R124-4 mention or breaching R124-2 is a 5th-class contravention ([R124-7](https://librejustice.fr/norm/fr/code-des-procedures-civiles-d-execution/r124-7)).
